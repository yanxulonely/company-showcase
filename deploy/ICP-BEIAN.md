# ICP 备案与 HTTPS 域名接入指南

适用于：尚润装饰展示站 · 腾讯云轻量服务器（上海）· 企业官网

> 备案免费，耗时约 **10～20 个工作日**。内地服务器**必须先备案**才能用域名正式对外访问。

---

## 一、备案前硬条件

| 条件 | 说明 |
|------|------|
| 腾讯云账号 | 已完成实名认证 |
| 轻量服务器 | 上海地域，在有效期内（当前 IP 示例：`106.54.246.16`） |
| 备案服务号 | 控制台 → 轻量服务器 → 备案 → 获取并绑定实例 |
| 域名 | 已购买，**实名认证通过** |
| 域名所有者 | 须为公司中文全称 / 公司拼音 / 法人姓名（与备案主体一致最省事） |
| 备案费用 | **免费** |

⚠️ **备案审核期间**：不要将域名解析到内地服务器对外访问，否则可能被拦截、影响审核。

---

## 二、个人备案 vs 企业备案

| 类型 | 适用 | 建议 |
|------|------|------|
| **企业备案** | 有营业执照的「尚润装饰」等公司 | ✅ **推荐** |
| **个人备案** | 无公司，个人名义建站 | 不推荐用于公司展示站 |

下文以 **企业备案 + 上海管局 + 普通企业展示网站** 为主。

---

## 三、企业备案材料清单

### 3.1 必需材料

| 材料 | 要求 | 上传方式 |
|------|------|----------|
| **营业执照** | 在有效期内；上海要求有效期 **>1 年**；含统一社会信用代码 | 彩色原件拍照或扫描，四角完整、清晰 |
| **法人身份证** | 正反面；有效期 **>3 个月** | 彩色拍照或扫描 |
| **主体负责人** | 上海规定：**必须是法定代表人** | 填写法人信息，与营业执照一致 |
| **网站负责人（ICP 负责人）** | 可以是法人或员工 | 若非法人，需授权书（见 3.2） |
| **法人手机号** | 可接收短信 | 全程核验 |
| **应急联系人手机** | 部分场景必填 | 建议同事/股东 |

### 3.2 上海常见补充材料

| 材料 | 何时需要 |
|------|----------|
| **上海 ICP 负责人授权书** | 网站负责人 **不是** 法定代表人时 |
| **上海市不涉及前置审批承诺书** | 普通企业展示站通常需要（盖公章） |
| **域名实名认证截图** | 域名非腾讯云注册，或系统要求补充时 |
| **域名证书** | 域名所有者为境外母公司时；国内公司自有域名一般 **不需要** |

模板下载：[腾讯云备案模板资料](https://cloud.tencent.com/document/product/243/113893)

官方材料说明：[备案所需材料](https://cloud.tencent.com/document/product/243/18914)

### 3.3 按场景准备的材料包

**场景 A：法人兼任网站负责人（最简单）**

- [ ] 营业执照（彩色）
- [ ] 法人身份证正反面（彩色）
- [ ] 域名（已实名，所有者 = 公司名）
- [ ] 备案服务号
- [ ] 上海市不涉及前置审批承诺书（盖章）
- [ ] 法人手机号

**场景 B：员工担任网站负责人**

在场景 A 基础上增加：

- [ ] 网站负责人身份证正反面
- [ ] 上海 ICP 负责人授权书（法人 + 负责人签字，盖公章）
- [ ] 网站负责人手机号

## 四、拍照与上传规范

| 规则 | 说明 |
|------|------|
| 必须原件 | 身份证、营业执照：彩色拍照或扫描 |
| 禁止 | 复印件、屏幕翻拍、黑白、模糊、缺角 |
| 边框完整 | 证件四边均在画面内 |
| 电子身份证 | 一般不接受 |

## 五、备案时需填写的信息

### 5.1 主体信息（公司）

| 字段 | 说明 |
|------|------|
| 主办单位名称 | 营业执照全称 |
| 单位性质 | 企业 |
| 证件类型 | 工商营业执照 |
| 证件号码 | 统一社会信用代码 |
| 通信地址 | 按页面要求填写 |
| 主体负责人 | **法人**姓名、身份证、手机 |

### 5.2 网站信息（服务）

| 字段 | 说明 |
|------|------|
| 网站名称 | 如「尚润装饰官网」（避免「新闻」「财经」「中国XX网」等） |
| 网站域名 | `www.xxx.com`、`xxx.com`（备案通过后再解析） |
| 服务内容 | 单位网站 / 企业展示 |
| 网站语言 | 简体中文 |
| 网站描述 | 建筑装饰公司展示：案例、设计师、能力介绍、在线咨询等 |
| 前置审批 | **无**（普通展示站） |
| 服务器 | 关联轻量实例 / 备案服务号 |
| ICP 负责人 | 实际维护网站的人员 |

### 5.3 网站名称注意

- ✅ 「尚润装饰」「尚润装饰官网」
- ❌ 含新闻、财经、医疗等需前置审批的字样
- 名称须与网站实际内容一致

## 六、上海管局特别要求（重要）

1. **主体负责人必须是法定代表人**
2. 网站负责人非法人 → 须 **上海 ICP 负责人授权书**
3. 法人未满 18 岁 → 不能备案
4. 个体工商户 → 上海 **不支持无公章** 备案
5. 外资企业 → 须持有 **上海本地营业执照**
6. **域名所有者** → 公司全称 / 拼音 / 法人姓名
7. **营业执照** → 彩色清晰，统一社会信用代码，有效期 **>1 年**
8. 普通展示站 → 填写 **不涉及前置审批承诺书**

详细：[上海管局备案要求](https://cloud.tencent.com/document/product/243/35819)（文档内搜索「上海管局」）

---

## 七、本网站是否需要前置审批

尚润装饰展示站（案例、设计师、能力、评价、留资）属于 **普通企业网站**，一般 **不需要**：

- 互联网新闻信息服务许可证
- 医疗 / 药品相关审批
- 广播电视节目制作等

若网站内容涉及新闻、出版、医疗等，须按管局要求提供专项审批文件。

## 八、备案操作流程

```
1. 打开 https://beian.cloud.tencent.com
   或微信搜索「腾讯云备案」小程序
2. 选择：首次备案 / 新增网站
3. 验证备案类型 → 绑定轻量服务器（备案服务号）
4. 填写主体信息 → 上传营业执照、法人身份证
5. 填写网站信息 → 上传承诺书、授权书（如需要）
6. 提交 → 腾讯云初审（约 1～3 工作日）
7. 工信部短信核验（收到后 24 小时内完成）← 超时会被退回
8. 上海管局审核（约 7～15 工作日）
9. 收到备案号 → 配置 DNS → 申请 HTTPS
```

**预计总耗时：10～20 个工作日**

## 九、备案通过后：域名 + HTTPS

### 9.1 DNS 解析

腾讯云 DNSPod → 添加记录：

| 主机记录 | 类型 | 记录值 |
|----------|------|--------|
| `@` | A | 服务器公网 IP |
| `www` | A | 服务器公网 IP |

### 9.2 防火墙

轻量服务器防火墙放行 **80**、**443**。

### 9.3 申请免费 SSL 证书

SSH 登录服务器后：

```bash
sudo apt update
sudo apt install -y certbot python3-certbot-nginx

sudo certbot --nginx \
  -d www.你的域名.com \
  -d 你的域名.com \
  --email 你的邮箱@example.com \
  --agree-tos
```

certbot 会自动配置 Nginx HTTPS 与 HTTP 跳转。续期测试：

```bash
sudo certbot renew --dry-run
```

### 9.4 页脚展示备案号

备案通过后，在管理后台「系统设置」页脚加入，例如：

```
© 2026 尚润装饰 | 沪ICP备2025xxxxxx号-1
```

## 十一、常见驳回原因

| 原因 | 避免方法 |
|------|----------|
| 证件模糊、缺角 | 重拍清晰彩色原图 |
| 域名未实名 / 所有者不是公司 | 域名控制台修改并实名 |
| 网站名称不合规 | 使用「公司名+官网」 |
| 主体负责人不是法人 | 上海必须填法人 |
| 短信核验超时 | 24 小时内完成工信部核验 |
| 备案期间域名已解析可访问 | 通过前勿解析 |

## 十二、与当前项目的关系

| 项目状态 | 说明 |
|----------|------|
| 代码 | 前端已用 `/api` 相对路径，**换域名无需改代码** |
| 数据库 | MySQL，数据在服务器 |

| 当前访问 | 可用 IP：`http://106.54.246.16/` |

## 十三、决策参考（要不要做）

| 继续做 IP 访问 | 做备案 + 域名 + HTTPS |
|----------------|------------------------|
| 零等待，立即可用 | 需 10～20 工作日 |
| 不适合正式对外品牌 | 专业、可分享、浏览器小锁 |
| 无 ICP 备案号 | 合规经营内地网站 |
| 适合内测、内部演示 | 适合给客户、对外营销 |
