# 文档区域说明

本目录用于存放项目的规划文档与程序设计文档，按版本号分文件夹管理，方便迭代追溯。

## 目录约定

```
docs/
├── README.md          # 本说明
├── 1.1/                # 版本 1.1：活动模块 + 项目架构升级
│   ├── 00-规划.md
│   └── 01-程序设计.md
├── 1.2/                # 版本 1.2（AI 生图暂缓；首页模块展示管理优先）
│   ├── 00-规划.md              # AI 生图 + 媒体库（暂缓）
│   ├── 01-程序设计.md          # AI 生图程序设计（暂缓）
│   ├── 02-首页模块展示管理-规划.md
│   └── 03-首页模块展示管理-程序设计.md
├── 1.3/                # 后续版本按需新建
│   └── ...
```

## 版本号规则

- 每次较大的功能迭代新建一个版本文件夹（如 `1.1`、`1.2`、`2.0`），文件夹内固定包含：
  - `00-规划.md`：本次迭代要做什么、为什么这么做、关键决策
  - `01-程序设计.md`：具体怎么实现（数据库表结构、API 接口、前端页面/组件、文件改动清单）
- 文档只做记录留存，不代表已实现；具体某项功能是否已落地以代码和 Git 历史为准。
